┌───────────────────────────────────────────────────────────────────┐
│ METHOD 1: Backend Terminal (See all incoming API requests)       │
└───────────────────────────────────────────────────────────────────┘

  Start backend:
  $ cd backend
  $ npm run dev

  You'll see:
  ============================================================
  📥 POST /api/v1/users/login
  ⏰ Time: 2/4/2025, 10:30:15 AM
  🔑 User: Not authenticated
  📦 Body: { "username": "johndoe", "password": "..." }
  📤 Status: 200
  ⏱️  Duration: 234ms
  ✅ Success
  ============================================================

  Symbols:
  📥 = Incoming request       📤 = Response
  ✅ = Success (200-299)      ❌ = Error (400+)
  🔑 = User making request    ⏱️ = Time taken
  📦 = Request body           🔍 = Query params

┌───────────────────────────────────────────────────────────────────┐
│ METHOD 2: Browser Console (See frontend API calls)               │
└───────────────────────────────────────────────────────────────────┘

  1. Press F12 (or Ctrl+Shift+I)
  2. Click "Console" tab
  3. Use your app (login, browse, etc.)

  You'll see:
  🚀 API Request: { method: "POST", url: "...", data: {...} }
  ✅ API Response: { status: 200, data: {...} }
  ❌ API Error: { status: 401, message: "..." }

  Filter logs:
  - Type "API" in filter box to see only API logs
  - Type "Error" to see only errors

┌───────────────────────────────────────────────────────────────────┐
│ METHOD 3: Network Tab (Most detailed)                            │
└───────────────────────────────────────────────────────────────────┘

  1. Press F12
  2. Click "Network" tab
  3. Refresh page
  4. Type "api/v1" in filter
  5. Click any request

  You'll see:
  - Full URL
  - Request/Response headers
  - Request payload
  - Response data
  - Status code
  - Time taken
  - File size

╔═══════════════════════════════════════════════════════════════════╗
║                      🐛 DEBUGGING GUIDE                           ║
╚═══════════════════════════════════════════════════════════════════╝

Problem: API not working

Step 1: Check Backend Terminal
  → Is request showing up?
  → What's the status code?
  → Any error messages?

Step 2: Check Browser Console
  → Any CORS errors?
  → Any 401 errors?
  → Is token being sent?

Step 3: Check Network Tab
  → Correct URL?
  → Request sent with correct data?
  → What was the response?

╔═══════════════════════════════════════════════════════════════════╗
║                   🔧 COMMON ERROR SOLUTIONS                       ║
╚═══════════════════════════════════════════════════════════════════╝

❌ Error: "CORS policy blocked"
   ✅ Fix: Check backend/.env has CORS_ORIGIN=http://localhost:3000
   ✅ Restart backend server

❌ Error: "401 Unauthorized"
   ✅ Fix: Login first (for protected routes)
   ✅ Check token in localStorage
   ✅ Try refreshing page

❌ Error: "404 Not Found"
   ✅ Fix: Check API URL is correct
   ✅ Check backend route exists
   ✅ Backend server running?

❌ Error: "500 Internal Server Error"
   ✅ Fix: Check backend terminal for error details
   ✅ Check database is running
   ✅ Check Cloudinary credentials

❌ Error: "Failed to fetch"
   ✅ Fix: Backend not running! Start with: npm run dev
   ✅ Check firewall/antivirus

╔═══════════════════════════════════════════════════════════════════╗
║                    📊 STATUS CODE MEANINGS                        ║
╚═══════════════════════════════════════════════════════════════════╝

200 OK              → Success! Everything worked
201 Created         → Resource created (user, video, etc.)
400 Bad Request     → Invalid data sent
401 Unauthorized    → Not logged in or token invalid
403 Forbidden       → Not allowed (not owner, etc.)
404 Not Found       → Resource doesn't exist
500 Server Error    → Backend error (check terminal)
